两行根数（Two-Line Element set，TLE）是 NORAD 沿用下来的一种固定宽文本格式。它的约束不在语义，而在**列位置**：每行恰好 69 个字符，字段宽度写死，小数点常常省略，校验位单独占一列。解析器出错，八成是列位置偏了一位，而不是数值算错。

## 第一行的字段

| 列 | 宽度 | 含义 |
|---|---|---|
| 1 | 1 | 行号，固定为 `1` |
| 3–7 | 5 | 卫星编号（NORAD catalog number） |
| 8 | 1 | 分类符，`U` 表示非保密 |
| 10–11 | 2 | 国际编号的发射年份后两位 |
| 12–14 | 3 | 该年的发射序号 |
| 15–17 | 3 | 同一次发射中的部件编号 |
| 19–20 | 2 | 历元年份后两位 |
| 21–32 | 12 | 历元：一年中的第几天加小数部分 |
| 34–43 | 10 | 平均运动一阶导数 |
| 45–52 | 8 | 平均运动二阶导数 |
| 54–61 | 8 | 阻力项 BSTAR |
| 63 | 1 | 星历类型，通常为 `0` |
| 65–68 | 4 | 根数序号，每更新一次加一 |
| 69 | 1 | 校验位 |

## 第二行的字段

| 列 | 宽度 | 含义 |
|---|---|---|
| 1 | 1 | 行号，固定为 `2` |
| 3–7 | 5 | 卫星编号，必须与第一行一致 |
| 9–16 | 8 | 轨道倾角，单位度 |
| 18–25 | 8 | 升交点赤经，单位度 |
| 27–33 | 7 | 偏心率，**省略了前导 `0.`**，`1234567` 表示 0.1234567 |
| 35–42 | 8 | 近地点幅角，单位度 |
| 44–51 | 8 | 平近点角，单位度 |
| 53–63 | 11 | 平均运动，单位圈每天 |
| 64–68 | 5 | 历元时刻的圈数 |
| 69 | 1 | 校验位 |

两个容易踩的坑：第二行偏心率必须补回 `0.` 再读；平均运动的单位是**圈/天**，转成角速度要乘 360 度，转成周期要取倒数后换算成秒。

## 校验位

校验位覆盖前 68 个字符，规则简单：数字按值累加，负号和句点各记 1，其余字符记 0，最后对 10 取模。校验位算不对，通常意味着这一行在传输中被截断或左移，而不是数据本身有问题。

## 数值怎么用

TLE 是平均根数，不能直接当成某一时刻的瞬时轨道要素做高精度外推。做位置预测时，先用 SGP4 一类模型把平均根数换算成瞬时状态，再叠加历元之后的传播时间；跨过历元越久，误差增长越快，低轨目标尤其明显。

解析脚本可以直接拿本站的 [TLE 数据分析器](/tools/tle_data_analyzer.html) 对照：它按列切分并逐项显示，便于核对自定义解析器的结果。
